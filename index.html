01 / The problem

Production failures are noisy.

Engineers must interpret logs, exceptions, traces and runtime context before deciding what actually caused an incident.

📜

Raw diagnostic noise

Request IDs, correlation IDs, timestamps, UUIDs and stack-trace details can obscure the semantic failure signal.

🔎

Historical search

Finding a previous incident with similar meaning is harder when wording and runtime context change.

🧩

Ambiguous causes

Categories such as Dependency ↔ Network and RaceCondition ↔ Database can overlap semantically.

05 / Research

What the experiments reveal.

The project compares preprocessing, semantic embeddings, classifier choices and retrieval behavior rather than reporting only one final model.

📈

Semantic embeddings beat TF-IDF

MiniLM + Logistic Regression + FAISS reports 96.83% accuracy versus 89.50% for the TF-IDF baseline.

🧹

Preprocessing matters

Removing dynamic identifiers and timestamps improves the reported accuracy from 94.17% to 96.83%.

🚀

Larger model can help

all-mpnet-base-v2 reaches a reported 97.33% accuracy, with a larger/slower embedding model.

🔍

Retrieval adds context

Similar historical failures provide additional evidence when classification confidence is imperfect.

⚡

Inference is lightweight

Reported end-to-end latency is 12–15 ms on GPU and 30–45 ms on CPU for the evaluated pipeline.

⚠️

Generalization remains open

Synthetic data, nine categories and fixed evaluation conditions require further real-world validation.

07 / Quick start

Reproduce the experiment.

Run the implementation from the repository's codebase/ directory.

terminal 
# Clone
git clone https://github.com/upadrastaharshavardhan/ai-failure-root-cause-NLP.git
cd ai-failure-root-cause-NLP/codebase

# Environment
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate

# Dependencies
pip install -r requirements.txt
python -m spacy download en_core_web_sm

# Reproduce
python scripts/generate_data.py --n-samples 3000 --seed 42
python scripts/train.py
python scripts/evaluate.py

# Launch Gradio demo
python -m src.api.gradio_app
